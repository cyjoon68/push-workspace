## 2. 플로우

### 시나리오 1 — 공고 등록부터 서류 확정까지
1. 앱을 열면 명령창. 공고 링크 붙여넣고 실행 (①)
2. 공고 분석 결과. 지원 준비 시작 (②)
3. 회사 채팅이 열리고 AI가 다음 행동 제안 (③)
4. "자소서 초안 만들어줘" → 초안 완성 카드 → 내 서류로 열기 (④)
5. 내 서류는 순수 편집기. 직접 고침 (④)
6. 채팅에서 "3번째 문장 수치 강조해줘" → 문서에 반영 (③)
7. 채팅의 문서 확정 승인 카드 → 승인 → PDF (③)
8. 지원 관리 카드 목록에서 READY (⑤)

### 시나리오 2 — 프로젝트 실행 승인부터 근거 반영까지
1. 채팅에서 "부족 역량 프로젝트 추천" → 블루프린트 카드 4개 (③)
2. 선택 → 채팅 목록에 전용 프로젝트 채팅 생성, 블루프린트 상세·실행 미리보기 카드 (③)
3. 실행 → 같은 채팅에 CLI 승인 카드(명령·디렉터리·프롬프트) (③)
4. 승인 → 실행 상태 카드 RUNNING → VERIFIED (③)
5. "근거로 추가" → 커리어 볼트에 반영 (⑧)

- 화면별 primary CTA: 로그인 → ①, 홈(명령창) → ①, 회사별 채팅 → ③, 내 서류 → ④, 지원 관리 → ⑤, 공고 상세 → ②, 커리어 볼트 → ⑧, 프로젝트(채팅 그룹) → ③, 면접 → ⑥, 캘린더 → ⑥, 설정 → ⑦

### 역추출 (2단계)

- 프로젝트 = 채팅 그룹. 사이드바에 별도 "프로젝트" 섹션 없음 — 프로젝트 채팅도 채팅 목록에 함께 나열 (태그로 구분)
- AI 상호작용은 채팅으로 일원화. 에디터 인라인 AI 없음
- 승인 카드는 전부 채팅 메시지 스트림 안
- 목록 화면은 카드 그리드 + 스켈레톤 로딩
- 로딩 스켈레톤은 실제 레이아웃 형태와 일치 (그리드면 그리드형 스켈레톤)
- 빈 채팅은 "비어있음" 문구 없이 제안 칩 + 입력창만 노출

### 역추출 (3단계 레퍼런스)

- 채택 방향: ChatGPT/Aside/Grok 계열 — 평면 채팅 목록, 중앙 대형 입력창(버튼 내부), 입력 아래 제안 액션, 최근 작업 카드, 사이드바 기능 섹션, 채팅 목록 실행 상태 점
- 기각: Paseo(전체), Notion(전체), Linear(전체) — 다중 패널·칸반·트리형 관리 UI 부정
- Grok ⑤ 우상단 모델 표시 불필요 (Push에 해당 기능 없음), 사이드바 하단은 계정만
- Craft 컬러 문서 카드 → 내 서류 목록에 색 구분 적용 가능
- Craft 사이드바 문장(깔끔·닫기 아이콘)은 사이드바 접힘 토글로 해석 — 기록만, 규칙 확정 때 확인
