## 제외 목록

| 쓰지 않음 | 이유 |
|---|---|
| arrow-left | 데스크톱 — 뒤로 버튼 없음, 사이드바 탐색 |
| x-circle | 닫기·거부는 x 하나만 |
| more-horizontal / ellipsis-vertical | 더보기는 ellipsis 하나만 |
| image-off | (미사용 — 이미지 중심 아님) |
| sparkles / bot / wand | AI 표시 아이콘 없음 — AI는 채팅 메시지로만 존재 (2단계 피드백) |
